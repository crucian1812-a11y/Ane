# photos/

Сюда попадают фотографии. В git они не коммитятся — архив цепляется к релизу,
а workflow распаковывает его в эту папку при сборке.

Хочешь посмотреть локально — просто накидай сюда файлы и запусти
`node scripts/build-gallery.mjs`.

Поддерживаются `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.gif`.
Порядок — по именам файлов, так что `01_`, `02_` работают как надо.

Папка `photos/thumbs/` — необязательные превью: если рядом лежит
`thumbs/<то же имя>`, в сетке покажется оно, а по клику откроется оригинал.
