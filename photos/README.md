# photos/

Сюда сборка распаковывает архив из релиза. В git эта папка не коммитится.

После обработки внутри появляется:

- `web/0001.jpg` — версия до 1600px, её показывает слайдшоу
- `thumbs/0001.jpg` — квадратное превью 500×500 для сетки
- `index.tsv` — соответствие «номер → исходное имя файла»

Оригиналы на сайт не выкладываются: они тяжёлые, а разницы на экране не видно.

Для локального просмотра можно просто накидать картинок прямо сюда и запустить
`node scripts/build-gallery.mjs` — они подхватятся как есть.
