# Сайт ко дню рождения

Статичный сайт: обложка с именем и обратным отсчётом, письмо, галерея и таймлайн.
Фотографии в репозиторий не коммитятся — они приезжают архивом из релиза, и сборка
сама распаковывает их и публикует на GitHub Pages.

## Как залить фотографии

1. Собери фото в один `.zip` (или `.tar.gz`). Вложенные папки внутри архива можно — они сохранятся.
2. На GitHub: **Releases → Draft a new release**, тег любой (например `photos-v1`), прикрепи архив файлом.
3. Нажми **Publish release**.

Дальше всё само: workflow скачает архив, распакует в `photos/`, пересоберёт список
и выкатит сайт. Новый архив — новый релиз, старые фото при этом не перетираются
(распаковка идёт поверх, одноимённые файлы заменяются).

Перед первым разом надо один раз включить Pages: **Settings → Pages → Source: GitHub Actions**.

## Что править руками

Весь текст живёт в одном файле — `site.config.js`:

| Поле | Что это |
|---|---|
| `name` | имя на обложке |
| `birthday` | день рождения в формате `MM-DD`, от него считается обратный отсчёт |
| `togetherSince` | дата в формате `YYYY-MM-DD`; убери значение — блок «дней вместе» исчезнет |
| `hero` | надпись сверху и подзаголовок |
| `letter` | письмо, каждая строка массива — абзац |
| `timeline` | важные даты; пустой массив — секция не показывается |
| `footer` | подпись внизу |

Подписи к фото — необязательный файл `photos/captions.json`:

```json
{
  "01.jpg": "Ялта, август",
  "2019/море.jpg": "Тот самый шторм"
}
```

Ключ — имя файла или путь внутри `photos/`.

## Локально

```bash
node scripts/build-gallery.mjs   # пересобрать список фото
python3 -m http.server 8000      # открыть http://localhost:8000
```

Просто открыть `index.html` двойным кликом тоже сработает — внешних запросов нет.

## Структура

```
index.html            разметка
site.config.js        все тексты и даты
assets/css/style.css  оформление
assets/js/main.js     счётчики, галерея, лайтбокс
assets/js/photos.js   генерируется сборкой, руками не трогать
photos/               фото (в git не попадают, приезжают из релиза)
scripts/              сборка списка фотографий
```
